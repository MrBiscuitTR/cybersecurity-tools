# data

Tiny static inputs only — small fixtures for tests and lookup tables (e.g. a
subdomain-takeover fingerprint list, a handful of DNS resolvers).

**No shipped wordlists or big signature dumps.** Those live on the Kali box
(`/usr/share/seclists`, `/usr/share/wordlists`, ...) and are passed to tools by
path. Keep this directory small enough to read at a glance.
